# GOALGPT AI — النسخة الأولى

## الملفات
- app.py: خادم Flask ومحرك التوقعات وواجهات API.
- templates/index.html: واجهة الموقع.
- static/style.css: التصميم الأسود والأخضر.
- static/app.js: التفاعل وعرض النتائج والسجل.
- requirements.txt: المكتبات.
- render.yaml: إعداد نشر Render.

## تشغيل محلياً
```bash
pip install -r requirements.txt
python app.py
```
ثم افتح `http://127.0.0.1:5000`.

## النشر على Render
1. ارفع محتويات هذا المجلد إلى مستودع GitHub.
2. في Render اختر New > Web Service ثم اربط المستودع.
3. Build Command: `pip install -r requirements.txt`
4. Start Command: `gunicorn app:app`
5. اختر Free للتجربة.

## تنبيه مهم حول التخزين
هذه النسخة تستخدم SQLite محلياً. تخزين الملفات المحلي في Render Free مؤقت وقد يُمسح عند إعادة التشغيل أو النشر؛ لذلك لا تعتمد عليها كسجل دائم. قبل إطلاق الموقع للعموم، نربط PostgreSQL دائم أو خدمة قاعدة بيانات مناسبة ونضيف حماية لوحة الإدارة.

## حدود البيانات
النسخة الحالية لا تجلب مباريات مباشرة تلقائياً. أدخل أسماء الفرق ومتوسطات الأهداف يدوياً. نتائج البوتات احتمالية مبنية على نموذج Poisson مبسط، وليست ضماناً للنتائج. نسب الأداء لا تُحسب إلا بعد تسجيل نتيجة المباراة.


## تفعيل جلب المباريات تلقائياً
1. أنشئ حساباً في API-Football: https://www.api-football.com/
2. خذ API Key من لوحة التحكم.
3. في Render افتح خدمة الموقع ثم Environment.
4. أضف المتغير `APISPORTS_KEY` وضع فيه المفتاح (لا تضع المفتاح في ملفات JavaScript أو GitHub).
5. أعد نشر الخدمة.

اختياري: أضف `FOOTBALL_TIMEZONE=Africa/Casablanca` لعرض أوقات المباريات بتوقيت المغرب.
الواجهة الجديدة تعرض مباريات التاريخ المختار، وتسمح بتحليل المباراة تلقائياً عبر إحصائيات الفريقين في الدوري والموسم.
الخطة المجانية لدى API-Football محدودة بعدد الطلبات اليومي؛ تجنب تحديث الصفحة بشكل متكرر. تحليل مباراة يستهلك طلباً للمباراة وطلبين لإحصائيات الفريقين.
إذا لم تتوفر إحصائيات موسم/دوري لفريق، سيعرض الموقع رسالة واضحة بدلاً من اختلاق الأرقام.
